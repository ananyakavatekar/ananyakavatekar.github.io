Chart 1: License Counts by Status

This visualization shows the number of license records by status for a selected state and license type. The X-axis uses nominal encoding for license status, while the Y-axis uses quantitative encoding for the number of records. A single color was used to avoid misleading associations between colors and license statuses.

Two dropdown menus allow users to select a state and license type, with Illinois selected by default. This allows users to explore the distribution of license statuses across different categories.

Chart 2: Active Licenses in Illinois

This visualization showcases the percentage of active licenses for each of the ten most common license types within Illinois in the dataset. License types are ordered in descending order based on their proportion of active licenses. The Y-axis uses nominal encoding and the X-axis uses quantitative encoding. A single color is used throughout.

I filtered the data to Illinois, selected the ten most common license types, and calculated the proportion of active licenses in each category.
